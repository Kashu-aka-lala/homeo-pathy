# Farooq Homeopathic EMR

A modern, responsive Electronic Medical Records (EMR) system tailored for **Farooq Homeopathic** and **Dr. Umar Farooq**.

![Farooq Homeopathic Logo](./public/logo.png)

## 🌟 Features

- 👥 **Patient Registry**: Comprehensive patient management with search, filter, and history tracking.
- 🩺 **Consultation Workflow**: Clinical notes, vitals recording (BP, Pulse, Weight, Temp), and symptom logs.
- 💊 **Homeopathic Remedy Builder**: Select from 50+ remedies, potencies (30C, 200C, 1M, LM scale), vehicles, and dietary precautions.
- 📄 **Branded PDF Generation**: Instant client-side PDF generation for Prescriptions and Invoices.
- 📱 **WhatsApp Dispatch**: Send formatted prescriptions and payment invoices directly to patients via WhatsApp.
- 💳 **Payment Account Info**: Integrated HBL Bank details for patient consultation fees.
- 💾 **Dual-Storage Engine**: Seamless cloud sync via Supabase, with automatic offline LocalStorage fallback.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack) & React 19
- **Styling**: Tailwind CSS v4 & Lucide Icons
- **PDF Engine**: `@react-pdf/renderer`
- **State Management**: Zustand
- **Backend / Database**: Supabase (PostgreSQL & Storage)

---

## 🚀 Getting Started

### Prerequisites
- Node.js 20+ installed.

### Installation & Running Locally

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3005`) in your browser.
